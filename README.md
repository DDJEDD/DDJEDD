## 💡 Why These Levels?
* **C++ & Low-level Networking (`Senior`):** You work directly with the operating system and network stack rather than relying on heavy, high-level abstractions. Implementing raw socket communication, managing manual asynchronous state machines, and parsing complex network streams (like `chunked` HTTP transfers) byte by byte reflects a senior systems-engineering mindset.
* **Python & Asyncio (`Middle`):** You build complete, production-grade distributed systems from scratch—featuring async FastAPI microservices, real-time WebSockets, non-blocking database operations, secure JWT auth, and containerization via Docker Compose.

---

## 🚀 Core Competencies
* **Systems & Networking:** Writing low-level socket clients and servers, manual protocol stream parsing, memory management, and designing custom asynchronous state machines in C++.
* **Microservices Architecture:** Designing decoupled services, implementing secure inter-service authentication (JWT via cookies), and managing independent service lifecycles.
* **Real-time Systems:** Building scalable real-time chat and data streaming applications using WebSockets and non-blocking I/O pools.
* **Infrastructure & DevOps:** Full deployment lifecycle—containerizing applications with Docker, managing multi-container environments in Docker Compose, and configuring Nginx and Linux server environments.
